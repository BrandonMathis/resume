My terminal is my development environment and there are a few specific commands that I use every day when I am coding. My shell of choice is zsh with oh-my-zsh installed

htop — Live resource stats

htop is an interactive process viewer that helps you visually see running processes and their impact on system memory, CPU and disk swap space. You can sort your running processes against a variety of criteria and send kill commands to them directly from the htop tool.

vTop — Resources over time

vTop is a shell script written in node that gives you an amazing visual breakdown of machine resource like CPU and memory usage over time.

z — Jump around

Using z you can quickly move from directory to directory without having to type out the entire path. Z Tracks your most used directories, based on ‘frecency’ and will match the directory you want to navigate to based on how frequently you navigate to it.

ag — The Silver Searcher

Want to quickly find all occurances of a specific word or phrase in a directory? AG is a code searching tool similar to ack but is an order of magintude faster and will respect your .gitignore and .ignore files.
